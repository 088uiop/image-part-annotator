# Image Part Annotator · 图片部位标注工具

一个用于给图片标注「部位区域」的单文件网页工具：在图上框选部位（如头部、手臂、尾巴…），自动把矩形换算成整图的百分比坐标，并导出成可直接被程序读取的 JSON。

不需要安装、不需要后端：只有一个 HTML 文件，双击用浏览器打开即可，图片不会上传到任何服务器。

---

## 功能特性

- **打开图片**：点击按钮选择，或直接把图片拖进画布（PNG / JPG / WEBP / SVG…）
- **部位管理**：可添加任意多个部位名称，每个部位可包含多个选区（如左臂、右臂）
- **框选即换算**：拖拽出矩形后立即得到百分比范围（x 从左到右、y 从上到下，保留两位小数）
- **PS 式视图操作**：`Alt + 滚轮` 以鼠标位置为锚点缩放；`空格 + 拖拽` 或中键拖拽平移；支持 `适应窗口` 和 `1:1`（1 图像像素 = 1 屏幕像素）
- **自由变换**：选中框后可拖动整体移动、拖 8 个控制点调整大小，可点选重叠区域
- **可折叠的部位列表**：每个部位展开后列出其选区（`手臂1`、`手臂2`…），点编号即选中对应框
- **逐框隐藏**：每个选区右侧的眼睛按钮可单独隐藏/显示，方便框选被大框遮住的区域
- **实时 JSON**：右下角实时预览，可一键复制或下载 `config.json`
- **导入 JSON**：可把之前导出的标注重新载入，继续补充或检查
- **画布标签带序号**：框左上角显示 `头部1`、`手臂2`，与左侧列表一一对应

## 快速开始

1. 下载 `image-part-annotator.html`
2. 双击用 Chrome / Edge / Firefox 打开
3. 点击「打开图片」载入一张图
4. 输入部位名（如「头部」）→ 点「添加」
5. 在图片上拖拽框选；同一部位可框多次（框 2 次就有了「手臂1」「手臂2」）
6. 右下角复制或下载 JSON

## 操作速查

| 操作 | 说明 |
| --- | --- |
| `Alt + 滚轮` | 以鼠标位置为中心缩放 |
| `空格 + 拖拽` / 鼠标中键 | 平移画布 |
| 在空白处拖拽 | 用当前部位新建一个选区 |
| `Ctrl + 拖拽` | 在已有框内部新建选框（避免被大框挡住） |
| 拖框内部 | 移动该选区（尺寸不变） |
| 拖角点 / 边中点 | 调整该选区大小 |
| 单击框 | 选中该框（出现白色描边与控制点） |
| `Delete` / `Backspace` | 删除选中的框 |
| 点部位左侧箭头 | 展开 / 折叠该部位的选区列表 |
| 点列表中的 `手臂2` | 选中对应的框（若被隐藏会自动显示） |
| 点列表右侧眼睛图标 | 隐藏 / 显示单个选区 |
| 框右上角 `✕` | 删除该框 |

## 输出的 JSON 格式

顶层键为部位名称；**该部位只有一个框时是对象，有多个框时是数组**：

```json
{
  "头部": {
    "x": { "min": 0.01, "max": 0.98 },
    "y": { "min": 0.11, "max": 0.55 }
  },
  "胸部": {
    "x": { "min": 0.37, "max": 0.59 },
    "y": { "min": 0.55, "max": 0.68 }
  },
  "手臂": [
    {
      "x": { "min": 0.20, "max": 0.37 },
      "y": { "min": 0.59, "max": 0.77 }
    },
    {
      "x": { "min": 0.59, "max": 0.75 },
      "y": { "min": 0.59, "max": 0.77 }
    }
  ]
}
```

坐标语义：

- `x.min` / `x.max`：矩形左边界、右边界，占整图宽度的比例（0 = 最左，1 = 最右）
- `y.min` / `y.max`：矩形上边界、下边界，占整图高度的比例（0 = 最上，1 = 最下）
- 与图片实际像素无关，换分辨率后仍然有效

按百分比取像素区域（JavaScript 示例）：

```js
const { x, y } = config["头部"];
const box = {
  left:   x.min * imgWidth,
  top:    y.min * imgHeight,
  width:  (x.max - x.min) * imgWidth,
  height: (y.max - y.min) * imgHeight,
};

// 同一部位可能是数组
const list = Array.isArray(config["手臂"]) ? config["手臂"] : [config["手臂"]];
```

## 导入已有标注

点左下角「导入 JSON」选择之前导出的 `config.json`，部位与选区会按百分比恢复到画布上（需要先打开一张图）。若部位重名，会自动追加序号避免冲突。

隐藏状态、折叠状态只用于编辑时的显示控制，不会写进 JSON。

## 隐私

- 图片只在本机浏览器中读取与显示，**不会上传**
- 没有网络请求；断网也能正常使用
- 建议使用较新的 Chrome / Edge / Firefox / Safari
